================================================================================
YOUR CHATBOT IS READY - START IT NOW!
================================================================================

The RAG chatbot is now integrated into your Docusaurus book project!

================================================================================
STEP 1: SET UP ENVIRONMENT (2 minutes)
================================================================================

cd hackathon-Project
cp backend/.env.example backend/.env

Edit backend/.env and add:
  OPENAI_API_KEY=sk-... (from https://platform.openai.com/api-keys)
  QDRANT_URL=https://... (from https://cloud.qdrant.io)
  QDRANT_API_KEY=... (from https://cloud.qdrant.io)
  NEON_DB_URL=postgresql://... (from https://neon.tech)

================================================================================
STEP 2: START BACKEND (Terminal 1)
================================================================================

cd backend
pip install -r requirements.txt
uvicorn app:app --reload

Wait for: "Application startup complete"

================================================================================
STEP 3: START FRONTEND (Terminal 2)
================================================================================

cd docusaurus-book
npm install  (only if not done before)
npm run start

Wait for: "Docusaurus server started on: http://localhost:3000"

================================================================================
STEP 4: OPEN YOUR CHATBOT
================================================================================

Open browser to:
  http://localhost:3000/chat

You should see the chat interface!

================================================================================
STEP 5: TEST WITH SAMPLE DATA (Optional, Terminal 3)
================================================================================

python scripts/ingest_documents.py --sample

This creates test documents so you can immediately ask questions.

================================================================================
HOW TO USE THE CHAT
================================================================================

1. Type a question about the book
2. Click "Ask →" or press Enter
3. See answers with source citations
4. Select text on any page
5. Click "Query Selection ✓" to ask about selected text

================================================================================
NEXT: INGEST YOUR BOOK
================================================================================

Once everything is working, ingest your actual book:

python scripts/ingest_documents.py --path docusaurus-book/docs

This will:
  • Read all markdown files from your book
  • Split into chunks
  • Generate embeddings
  • Store in Qdrant and PostgreSQL

Then your chatbot can answer questions about your book!

================================================================================
TROUBLESHOOTING
================================================================================

Chat page doesn't load?
  → Check http://localhost:8000/health
  → Restart: npm run start in docusaurus-book/

No response from chatbot?
  → Check backend is running: http://localhost:8000/docs
  → Check .env has correct API keys
  → Check browser console (F12) for errors

API connection error?
  → Verify CORS_ORIGINS in backend/.env includes http://localhost:3000
