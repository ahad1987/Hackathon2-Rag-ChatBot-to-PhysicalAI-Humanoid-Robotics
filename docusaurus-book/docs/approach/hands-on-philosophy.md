# Hands-On Philosophy

This book believes in **learning by doing**.

## Why Hands-On?

Reading about robotics is different from building it.

- **Theory alone is abstract**: Terms feel disconnected from reality
- **Code examples ground learning**: You see concepts in action
- **Building creates intuition**: Your hands understand what theory teaches

## Progressive Complexity

Each chapter builds on the last.

- Start with simple concepts (what is a node?)
- Add complexity gradually (how do nodes communicate?)
- Practice before advancing (write a publisher, then a subscriber)
- Apply knowledge to real systems (control a robot arm)

## Code Examples in Every Chapter

You'll see practical Python code in every chapter.

- All examples are tested and work
- Explanations appear every 3-4 lines
- Output is shown so you know what to expect
- Advanced features are avoided (keep it beginner-friendly)

## Glossary as Reference

Every technical term is defined in the glossary.

- Look up terms you don't know
- See how they connect to other concepts
- Use definitions as you code and experiment

## Progressive Learning Path

```
Foundation (What is it?)
    ↓
Concepts (How does it work?)
    ↓
Code Examples (How do I use it?)
    ↓
Troubleshooting (What if it breaks?)
    ↓
Real Applications (Where does it matter?)
```
