# Prerequisites

This book assumes **no prior robotics experience**. But you'll need a few basics.

## Knowledge Prerequisites

**Python basics**:
- You should know how to write simple functions
- Understand loops and conditionals (if/else)
- Know what a class is (we explain OOP details as we go)

**Not required**:
- Robotics experience
- C++ or other languages
- Machine learning expertise
- Hardware knowledge (we teach it)

## Hardware Prerequisites

To run the code examples, you have options.

**Option 1: Simulation Only** (recommended to start)
- No hardware needed
- Run ROS 2 on your computer
- Use simulated robots
- Great for learning

**Option 2: Physical Robot** (next step)
- Raspberry Pi or similar single-board computer
- ROS 2-compatible robot kit
- USB cables and power supply
- About $300-500 for a starter kit

**Option 3: Cloud-Based** (flexible)
- Set up ROS 2 in a cloud environment
- No local hardware required
- Docker containers recommended

## Software Prerequisites

You'll need to install:

- **ROS 2 Humble** (the version we teach): [installation guide](https://docs.ros.org/en/humble/Installation.html)
- **Python 3.8 or newer**: [python.org](https://www.python.org/)
- **Text editor or IDE**: VS Code, PyCharm, or similar
- **Git**: For version control and example code

Installation takes about 30 minutes and we provide step-by-step guides.

## Time & Effort

**Learning time**:
- Each chapter takes 30-60 minutes to read and practice
- Module 1 takes about 4-6 hours total
- Budget extra time to experiment and break things

**Why break things?**
- Breaking and fixing teaches deep understanding
- It's how real engineers learn
- All examples are safe to experiment with
