HOW TO USE YOUR CHATBOT
================================================================================

1. Type a question in the chat box
   Example: "What is the main topic?"

2. Click "Ask →" or press Enter

3. Get response with:
   • Short answer (1-3 sentences)
   • Long explanation
   • Source citations
   • Confidence score
   • Processing time

4. Select text on page

5. Ask about selection

6. Click "Query Selection ✓"

7. Get answer from just that text!

================================================================================
IF SOMETHING DOESN'T WORK
================================================================================

Chat page doesn't load?
  → Check: http://localhost:3000/ (main site loads?)
  → Check: docusaurus-book/src/pages/chat.tsx exists
  → Try: npm run start

No response from queries?
  → Check: http://localhost:8000/health (returns JSON?)
  → Check: backend/.env has all API keys
  → Check browser console (F12) for errors

API connection error?
  → Restart backend: uvicorn app:app --reload
  → Check CORS_ORIGINS in backend/.env includes http://localhost:3000

No documents found?
  → Run: python scripts/ingest_documents.py --sample
  → Then ask again
