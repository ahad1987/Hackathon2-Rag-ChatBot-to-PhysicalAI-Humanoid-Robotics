INSTALLATION (5 MINUTES)
================================================================================

Step 1: Clone & Setup Environment
  cd hackathon-Project
  cp backend/.env.example backend/.env

  ⚠️  IMPORTANT: Edit backend/.env with your API keys:
      - OPENAI_API_KEY (from https://platform.openai.com/api-keys)
      - QDRANT_URL & QDRANT_API_KEY (from https://cloud.qdrant.io)
      - NEON_DB_URL (from https://neon.tech)

Step 2: Install Backend (Terminal 1)
  cd backend
  python -m venv venv
  source venv/bin/activate  # or: venv\Scripts\activate (Windows)
  pip install -r requirements.txt
  uvicorn app:app --reload

  ✓ Backend running at http://localhost:8000

Step 3: Install Frontend (Terminal 2)
  cd docusaurus-book
  npm install
  npm run start

  ✓ Frontend running at http://localhost:3000

Step 4: Verify Installation (Terminal 3)
  bash verify_rag.sh

  ✓ All tests should pass

Step 5: Open Chat UI
  http://localhost:3000/chat

================================================================================
TROUBLESHOOTING
================================================================================

Backend won't start:
  ✓ Check Python version: python --version (need 3.11+)
  ✓ Check virtual env: pip list (should show fastapi, openai, etc.)
  ✓ Check .env file: cat backend/.env (verify all keys are filled)
  ✓ Install deps: pip install -r backend/requirements.txt

Frontend won't start:
  ✓ Check Node version: node --version (need 18+)
  ✓ Install deps: npm install
  ✓ Check port: kill -9 :3000 (if port already in use)

Queries return poor results:
  ✓ Re-ingest documents: python scripts/ingest_documents.py --sample
  ✓ Increase TOP_K_RETRIEVAL in backend/.env
  ✓ Check Qdrant collection: https://your-cluster.qdrant.io/collections

Services won't connect:
  ✓ Check CORS: curl -i http://localhost:8000/health
  ✓ Check API keys: echo $OPENAI_API_KEY (should not be empty)
  ✓ Check database: psql $NEON_DB_URL -c "SELECT 1;"

See detailed troubleshooting in RAG_SETUP_GUIDE.md
